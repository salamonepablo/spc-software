## Technical Notes

### Current Account Dual-Line Logic
```
Billing (L1): Invoices, Credit Notes, Debit Notes, Payments L1
Budget (L2):  Quotes, Payments L2

TotalBalance = BillingBalance + BudgetBalance
```

### Quote Impact on Current Account
```csharp
// On Create - increases debt
await _currentAccountService.RecordMovementAsync(
    customerId: request.CustomerId,
    documentType: DocumentType.Quote,
    documentNumber: quote.QuoteNumber,
    billingAmount: 0,           // No impact on L1
    budgetAmount: quote.Total,  // Positive = customer owes us
    description: $"Presupuesto {code}-{number}");

// On Void - decreases debt
await _currentAccountService.RecordMovementAsync(
    customerId: quote.CustomerId,
    documentType: DocumentType.QuoteVoid,
    documentNumber: quote.QuoteNumber,
    billingAmount: 0,
    budgetAmount: -quote.Total,  // Negative = reduce debt
    description: $"Anulación Presupuesto...");
```

### License Feature Check
```csharp
// Budget balance only updates if feature is enabled
if (_licenseService.IsFeatureEnabled(Features.DualLineCurrentAccount))
{
    account.BudgetBalance += budgetAmount;
}
// Billing always updates regardless of license
account.BillingBalance += billingAmount;
```
